# pavo docs

VitePress + Diátaxis site — the docs worktree of `main` (orphan
branch `docs`). From the repo root, `cargo xtask site` runs
`docs:gen` + `vitepress build`. The crate map
(`explanation/architecture.md` marker + `reference/crate-api.md`)
is generated by `gen-crate-map.py` — never hand-edit it; keep
`lib.rs` module docs and Cargo.toml descriptions accurate.
`public/api/` rustdoc is generated by `gen-api.py` (`docs:api`).
