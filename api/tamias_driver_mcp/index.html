tamias-driver-mcp — the MCP surface driver: given any engine driver’s ops manifest (<driver> ops), it serves those ops as MCP tools over stdio — tools/list derives a tool + inputSchema per op, tools/call dispatches through the target’s cli.* wire query. Engines ship zero MCP code; any MCP client (agent IDE, orchestrator) reaches their ops through one binary.

tamias-driver-mcp kuda          # stdio MCP server fronting tamias-driver-kuda
tamias-driver-mcp ./target/debug/tamias-driver-kuda

surfaces entries (watch, mcp, acp) never become tools — a tools/call must terminate. Reach them through tamias-driver-cli.

Discovery verbs: manifest / capabilities / serve answer honestly — a surface, not a view provider (empty types, views → []).
