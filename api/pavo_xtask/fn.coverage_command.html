The cargo llvm-cov argv — pure so tests can pin the flags. --no-cfg-coverage: don’t set cfg(coverage), so the #![cfg_attr(coverage, feature(coverage_attribute))] crate attrs stay inert and stable rustc can instrument (nothing uses #[coverage(off)]). LLVM_COV/LLVM_PROFDATA may need to point at a system llvm when rustup’s llvm-tools-preview is absent.
