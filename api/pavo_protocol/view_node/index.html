Module view_node 

Source
Expand description

ViewNode IR — the declarative UI tree drivers emit and every pavo renderer (CLI, TUI, web) interprets.

Wire shape: each node is a JSON object with a "kind" discriminator (internally tagged — no wrapper envelope):

{ "kind": "table", "title": "Board", "query": "items",
  "columns": [{ "key": "id", "title": "ID" }],
  "rows": [["T-001", "pavo scaffold"]] }

Nodes bind to data through NodeBase::query, which names a crate::manifest::QueryBinding in the enclosing [ViewSpec]; the host resolves bindings to view-model data before rendering. Renderers that don’t know a kind must degrade to a generic key/value rendering rather than failing — forward compatibility is a host obligation.
