Fields§

§name: String

Driver name — the <type> in tamias-driver-<type> and the namespace for its routes (/<name>/<view>).

§title: String

Human-facing title for chrome (navbar entries, window titles).

§icon: Option<String>

Optional icon — an emoji, an icon name, or a path the renderer knows how to resolve.

§version: String

Driver version (semver string).

§verbs: Vec<String>

Wire verbs this executable answers beyond the tamias install verbs — e.g. ["manifest", "serve"] for pavo drivers. Capability-negotiated: pavo treats a driver as a view driver iff serve is listed (or capabilities contains "pavo").

§capabilities: Vec<String>

Capability tags — free-form strings products use to declare roles ("pavo", "config", "chrome").

§contributes: Contributes

Contribution slots — where this driver’s entries land in the composed chrome. See Contributes.

§views: Vec<ViewSpec>

Views this driver can render — each binds a route to a declarative ViewNode tree plus the queries that feed it.

§renderers: Vec<RendererDecl>

View-kind renderer plugins this driver ships — each declares the node kinds it renders and which surfaces it supports. See RendererDecl. A driver may declare renderers with zero views (pure renderer plugin) or alongside views.
