Module serve 

Source
Expand description

The ndjson serve loop — one Request per line on stdin, one Response per line on stdout. Nothing else may touch stdout.

This is the loop every pavo driver re-implements identically (myco-driver, cuora-driver, sepia-driver-pavo, tamias-driver-tamias, sturn-driver, mimus-driver, bupha-driver, pavo-driver-config); the kit absorbs it.
