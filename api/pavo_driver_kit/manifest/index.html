Module manifest 

Source
Expand description

Manifest builders — DriverManifest, ViewSpec, QueryBinding, and Contribution as fluent data, not struct literals.

The shapes are pavo-protocol’s; the kit only removes the noise: sensible defaults (verbs: ["manifest","serve"], capabilities: ["pavo"], priority 100), push-style slot methods, and the two query-binding conventions drivers keep rewriting — the own-driver query op (query) and the cross-driver QueryBinding.driver binding (foreign_query).
