pub fn foreign_query(driver: &str, name: &str, product_op: &str) -> QueryBinding
Expand description

A QueryBinding resolved against a foreign driver — the cross-driver half of the query contract (QueryBinding.driver). The host issues the binding’s op against driver’s serve instead of the view’s own; product_op rides in params["query"] like query.

let b = kit::foreign_query("config", "cfg", "get");
assert_eq!(b.driver.as_deref(), Some("config"));
assert_eq!(b.params["query"], "get");
