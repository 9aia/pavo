ViewNode constructors — the declarative tree as function calls instead of nested struct literals (or JSON).

Every kind function takes the shared NodeBase fields first (impl Into<NodeBase> — pass base()’s builder or NodeBase::default()), then the kind-specific payload. Part helpers (table_column, pair, field, tree_item, vertex) cover the sub-structs; anything not covered is a public-field mutation away.

let tree = kit::panel(
    kit::base().title("Board").query("items"),
    vec![
        kit::table(
            kit::base(),
            vec![kit::table_column("id", "ID"), kit::table_column("title", "Title")],
            vec![vec!["T-1".into(), "ship it".into()]],
        ),
        kit::kv(kit::base().title("Counts"), vec![kit::pair("open", 3)]),
    ],
);
assert_eq!(tree.base().title.as_deref(), Some("Board"));
