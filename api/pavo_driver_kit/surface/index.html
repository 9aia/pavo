Module surface 

Source
Expand description

The surface-driver layer — an engine’s ops manifest rendered onto real surfaces (a generated CLI, an MCP tool server) by drivers that know drivers, so engines stay blind.

A view driver exposes its engine’s verbs two ways: the ops argv verb (or {"op":"query","query":"ops"} wire query) answers an ops manifest — {engine, invoke, ops:[{query,doc,params,mutates}], surfaces} — and each op is reachable as a cli.<name> wire query whose data is {op, argv, code, stdout, stderr} (the engine ran in a captured child, never on the serve stream). Surface drivers consume exactly that contract:

  • cli (feature cli) — ops manifest → a generated clap CLI: op → subcommand, params → args. tamias-driver-cli is the standalone binary; an engine driver can also link the kit and serve its own ops in-process (tamias-driver-kuda cli …).
  • mcp (feature mcp) — ops manifest → MCP tools over stdio: op → tools/list entry with a generated inputSchema, call → tools/call. tamias-driver-mcp is the standalone binary.
  • client (feature client) — the process side standalone surfaces need: tamias-driver-<name> discovery, ops manifest fetch, one-shot wire queries, run passthrough.

OpSpecs carry typed params so surfaces never guess:

kindCLI spellingwire paramMCP schema
argpositional <name>{"name":s}string, required
opt--name <v> / --name=v / bare --namestring or truestring
flag--name{"name":true}boolean

A manifest that still lists params as bare strings ("params": ["name"]) parses each as opt — the permissive kind, accepted as --name, --name v, or --name=v.

Secret-bearing params. A ParamSpec may set "secret": true to declare that its value must not ride argv (shell history, /proc). Surfaces honor it declaratively: the generated CLI adds --params-stdin to every op — a JSON object on stdin merged over the argv params (stdin wins per key) — and warns on stderr when a secret param still arrives via argv (the value itself is never echoed). MCP tools/call already carries JSON arguments, so no argv leak exists there and it needs nothing extra.

surfaces names the engine’s unbounded surfaces (watch, mcp, acp, …) — verbs that never return and so can never be request/response ops. The CLI surface exposes them as streaming subcommands (argv passthrough, inherited stdio); the MCP surface omits them — a tool call must terminate.
