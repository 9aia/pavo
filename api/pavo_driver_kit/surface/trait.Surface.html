Expand description

The dispatch surface implementations plug into — one op runner (captured: request/response) plus one unbounded-surface runner (streaming: inherited stdio). Two implementors exist:

  • client::DriverClient (feature client) — a spawned tamias-driver-<type>; op = one-shot cli.<name> wire query, surface = run <name> <args> with inherited stdio.
  • an engine driver’s own impl — op reuses its cli.* dispatch, surface calls its engine lib in-process.

fn surface(&mut self, name: &str, args: &[String]) -> i32

Run one unbounded surface verb (watch, mcp, acp) with trailing argv — streams until the engine stops it. Default: report unsupported (exit 2); implementors that front a run passthrough override.
