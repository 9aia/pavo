pavo_driver_kit::surface

Module client 

Source
Expand description

The process side of surface drivers — discovery and one-shot wire calls against a spawned tamias-driver-<type>. Standalone surface binaries (tamias-driver-cli, tamias-driver-mcp) are thin mains over DriverClient; an engine driver embedding a surface implements Surface itself and never spawns.

Discovery mirrors the tamias driver contract: tamias-driver-<name> on PATH, then <tamias-home>/drivers/ ($TAMIAS_HOME → $XDG_DATA_HOME/tamias → ~/.local/share/tamias). A name that is (or resolves to) an existing file — any arg containing a path separator — is used as-is, which keeps tests and developer builds (target/debug/tamias-driver-kuda) trivially usable.
