The view verb’s format dispatch — returns the exact bytes to print (split from cmd_view_host so tests can assert on output).

Precedence: renderer plugins are consulted for every format before the built-in interpretation runs — text/dot/mermaid substitute claimed nodes’ RenderModels per tree path and keep the built-in rendering for unclaimed nodes. json is exempt (the raw ViewResult dump is host-owned). Any other format string is a plugin-only format: every claimed node’s RenderModel is emitted; no claims → usage error naming the built-ins.
