Module http 

Source
Expand description

Minimal HTTP/1.1 primitives for pavo serve — a hand-rolled localhost server (std-only, no async runtime, no deps).

Scope is deliberately narrow: GET/HEAD-style JSON APIs plus static file serving for the Nuxt build output. read_request parses one request off a TcpStream with hard caps on head and body size; Response serializes status line + headers + body with optional CORS. Keep-alive is supported — the caller loops until the client closes or sends Connection: close.
