Interactive-form editing state for the TUI.

A FormSession opens when the user presses Enter on a form field (or the form’s submit row) in the canvas — the model marks those rows via crate::model::FormMark. While a session is open the app routes keys here instead of the normal bindings: arrows/Tab move between editable fields, printable chars edit the focused field’s LineEdit buffer, Enter submits through the worker (submit wire op), Esc discards.

Field kinds: text/textarea/number (and unknown kinds) edit as a single-line buffer; select cycles options; bool toggles. editable:false fields render read-only on the canvas and never enter a session’s submitted values.
