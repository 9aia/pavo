pavo-tui — the ratatui host surface for pavo.

pavo-tui discovers pavo-capable tamias drivers (Host::discover), merges their chrome contributions into a tab bar + status bar, and interprets each driver’s ViewNode IR natively on a three-pane canvas: driver rail │ view canvas │ detail pane.

Non-interactive modes:

  • pavo-tui --list — print discovered drivers + views, exit.
  • pavo-tui --help — usage.

Deep links: pavo-tui demo:board, --view demo:board, or --driver demo (first view) land directly on a view.

worker 🔒
Background Host thread — pavo-core is sync and can block on driver serve round-trips (spawn, manifest fetch, view resolve), so it lives on a worker thread; the TUI loop talks to it over two mpsc channels and never freezes on a hung driver (DriverClient’s own timeouts bound each request).
