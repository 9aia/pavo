pub fn plugin_nodes(
    root: &ViewNode,
    registry: &RendererRegistry,
    surface: &str,
    format: Option<&str>,
) -> Vec<PluginNode>
Expand description

Find every node in root’s tree claimed by a renderer plugin for surface/format, pre-order, with stable PluginNode::path keys. Nodes whose kind has no plugin claim are skipped — callers fall back to built-in rendering for them.

data is unused here (kept out of the signature — plugins resolve bindings themselves from the data map they’re handed); it lives on PluginNode::node only via the node’s own query field.
