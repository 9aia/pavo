Struct DriverClient 

Source 
pub struct DriverClient { /* private fields */ }
Expand description

Client for one driver’s serve verb.

Spawn with DriverClient::spawn; issue typed requests with the manifest/views/view/query helpers or the generic DriverClient::request. Dropping kills the child.
