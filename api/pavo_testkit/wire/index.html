Module wire 

Source
Expand description

Raw ndjson wire session — spawn <driver> serve, send one JSON line, read one JSON line back, with a per-request timeout.

This is the transport crate::conformance and crate::record are built on; it’s pub so tests can speak malformed lines or probe transport failures the typed helpers don’t cover. Sync only — a stdout reader thread feeds an mpsc channel so recv_timeout gives the timeout without an async runtime (same shape as pavo-core’s DriverClient).
