Record/replay — capture a driver’s ndjson session to a transcript and replay it deterministically.

record_session speaks a list of requests to a live driver and stores every request/response pair as a Transcript; save_transcript/load_transcript persist it as JSON. replay_driver turns a transcript into a FixtureDriver that answers each request from the recording (matched on canonical JSON) — renderer and host tests run against it without spawning the real driver, and get byte-identical responses every run.
