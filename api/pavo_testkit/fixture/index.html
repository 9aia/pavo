FixtureDriver — a builder that materializes a fake tamias-driver-<name> executable in a tempdir.

The generated driver is a Python 3 script (stdlib only, mirroring the shell-script fixture style used across pavo-core/pavo-cli tests but able to answer configurable JSON instead of pattern matching). It implements:

  • tamias-driver-<name> manifest — prints the manifest verbatim (what pavo discovery probes).
  • tamias-driver-<name> capabilities — advertises pavo/serve.
  • tamias-driver-<name> serve — the ndjson wire: manifest, views, view, query, plus ok:false for unknown ops and malformed JSON.

Behaviour is driven by a sibling <name>.fixture.json config the builder writes next to the executable — manifest, view specs, canned query payloads, a raw views override, per-op error injection, a failure-mode block, or a recorded Transcript for deterministic replay.
