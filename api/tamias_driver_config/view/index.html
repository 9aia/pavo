Manifest + view specs — the pavo-facing half of the driver.

One namespace, config: deep links config:show and config:sources, queries get/set/resolve/config/sources. Other drivers and products call the query op over the serve wire — this is the “common config API” seed: namespaced dotted keys (myco.theme), never raw file paths.
