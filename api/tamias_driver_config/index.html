tamias-driver-config — the common config API driver for the 9aia suite. Graduated from examples/drivers/config (the Python prototype); now a first-party Rust driver in the pavo workspace.

Answers pavo’s wire ops (manifest/views/view/query/render/ submit) over serve, plus the sibling CLI verbs manifest and capabilities. The query surface is the product-facing API:

queryparamsresult
getkey (dotted){key, value, found}
setkey, value{key, value, path, written}
resolve—merged config tree (nested)
config—merged config flattened to KV
sources—every contributing layer

Other drivers read config by calling tamias-driver-config serve query get/resolve — namespaced keys (myco.theme), never raw files. Resolution order and write-back rules live in config’s module docs; the user-facing contract is the crate README.
